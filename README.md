## 🚀 How to run any product (single click)

Every product is a static website — zero backend, zero install, zero accounts.

**Option A: GitHub Pages (free, recommended)**
1. Create a new public repo on GitHub.
2. Upload this folder's contents to the repo.
3. In the repo → **Settings → Pages**, set Build source to **Deploy from a branch** → `main` → `/ (root)` → **Save**.
4. Your site is live at `https://<your-username>.github.io/<repo-name>/lunar-gardener/`

**Option B: Run locally**
Open any `index.html` file directly in your browser. No build step required.

**Option C: Vercel / Netlify (free tiers)**
Drag and drop the folder onto [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop) for an instant public URL.

## 🧠 Design Principles

- **No auth walls** — unless privacy genuinely requires it (and you tell me to add it).
- **Mobile-first, accessible** — ARIA labels, keyboard navigation, reduced-motion support, high-contrast text.
- **Offline-capable** — pure client-side code works without internet after loading.
- **Research-inspired** — ideas pulled from nature, science, culture, food, art, medicine, and actual research papers.

## 🛠️ Tech Stack

Plain HTML5 + CSS3 + vanilla JavaScript. No frameworks, no bundlers, no npm. Deployable in one click.
