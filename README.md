# Daily Products

Two useful tools for regular people. No logins, no paywalls — just open the URL and use it.

| Product | What it does | Live |
|---------|--------------|------|
| 🚗 **ShadeSide** | Enter start, destination, and departure time — see which side of the car to sit on to avoid sun glare. | https://kartikist.github.io/daily-products/shadeside/ |
| 🌙 **Lunar Gardener** | See the current moon phase and what to plant in your garden today. | https://kartikist.github.io/daily-products/lunar-gardener/ |

No login, no paywall. Open any `index.html` to run locally.
